# GitHub pages
Deploy a simple HTML website using GitHub Pages.
# Steps
1. Push it to a new GitHub repo. 
2. Go to repo → Settings → Pages → enable GitHub Pages. 
3. Select main branch and root folder. 
4. Access live website from the link GitHub gives. 
5. Try customizing with CSS.
# Enable GitHub pages
1. Open your new repository.
2. Click Settings.
3. In the sidebar, select Pages under Code and automation.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the branch main.
6. Select the folder /(root).
7. Click Save.
# Get your live website link
1. You can find the confirmed URL in your repository under Settings → Pages. 
2. Open it to verify that your website loads correctly.
# Customize your website
1. Try changing these CSS values inside the <style> section:
2. background: #16325c; — changes the header and footer color.
3. font-family: Arial, sans-serif; — changes the text style.
4. border-radius: 10px; — changes the roundness of the cards.
5. padding: 40px 20px; — changes the spacing around sections.
6. Commit and upload your changes to GitHub. 
7. GitHub Pages will automatically redeploy the website.
# Expected outcome
1. You will have a working static website hosted on GitHub Pages. 
2. Understand how to publish HTML and CSS files and know how to update your website through GitHub.
